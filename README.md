App written in python created as part of academic project. The program offers basic image manipulation features. 
Developed in collaboration with Kamil Iwaniak in 2023.
Looking back from my current perspective, I recognize several architectural flaws, such as the overuse of global statements and a lack of modular separation, which affect readability.
However, I decided to keep this project because it delivers functional app (basic image manipulation and histograms) and serves as a point of reference for how much my understand of clean code has evolved since then.
